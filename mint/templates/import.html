Upload the Mintresponse Work Order List workbook (.xlsx) or a CSV with the same column headings.

How importing works

  • The app finds the header row that contains WO # (row 10 in the tracker) and reads every row below it.
  • Each row is matched on WO #: new numbers are added, existing ones are updated. Nothing is deleted.
  • Only the entered (yellow) columns are read. Formula columns are recalculated by the app.
  • The file is treated as the source of truth: a blank cell clears that value in the app. Columns that are not in the file at all are left as they are.
  • Rows with invalid values (e.g. a status that is not in the drop-down list, or a negative amount) are skipped and listed below, so you can fix them in Excel and import again.
  • Need a fresh copy of the tracker? Download the blank template.
