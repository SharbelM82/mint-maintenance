# Mint Response — ORIGINAL source + requested changes

Start with [START_HERE.md](START_HERE.md).

This project is based on the uploaded `remix-mint-response-llc.zip`, not the previously redesigned v3.x site. Requested edits are documented in `docs/CHANGE_LOG.md`. The original export and instruction document are retained under `reference/` for review, not served by the website build.

## Quick start

Install Node.js 22, open this folder in Cursor and run:

```sh
npm install
npm run verify
npm run dev
```

Open `http://127.0.0.1:3000`. First install creates a real `package-lock.json`; review and commit it. Then use `npm ci` for repeat installs.

`npm run verify` runs the dependency-resolved TypeScript check, tests and the actual Vite/worker build. Dependency downloads were unavailable in the preparation environment, so that full command must still be run. The delivered code passed 24 dependency-free tests and 17-file TSX/TypeScript syntax transpilation, not a complete Vite build or a browser visual regression suite.

The production output is `dist/`, generated by `npm run build`. Use Cloudflare Pages for the included backend; GitHub stores the source and does not by itself provide the backend. Do not upload the review HTML as the production website.

## Useful commands

```sh
npm test              # 24 original-content and backend tests; no real network calls
npm run lint          # Full TypeScript check, after installing dependencies
npm run build         # Vite app + Cloudflare advanced-mode _worker.js
npm run preview       # Local preview of dist + the same server API handler
npm run preview:html  # Review-only, CDN-dependent single-file HTML
```

The form is not live until the owner configures and tests `CONTACT_FORM_ENDPOINT`. See `docs/FORM_SETUP.md`. The original normal form/receipt appearance is retained. Failures use a native alert and never produce a fake success.
